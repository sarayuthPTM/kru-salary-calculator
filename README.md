# ระบบคำนวณเลื่อนเงินเดือน & วางแผนอนาคตข้าราชการครู (ก.ค.ศ. ว20)

เว็บแอปพลิเคชันสำหรับคำนวณการเลื่อนเงินเดือนข้าราชการครูและบุคลากรทางการศึกษาแบบฐานบน-ฐานล่าง ปัดเศษหลักสิบ จำลองเส้นทางความก้าวหน้าเงินเดือนถึงอายุ 60 ปี และคำนวณประมาณการเงินบำนาญ กบข. อ้างอิงตามเกณฑ์มาตรฐาน ก.ค.ศ.

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **คำนวณการเลื่อนเงินเดือนแต่ละรอบ (1 เม.ย. / 1 ต.ค.):**
   - รองรับทุกอันดับ: **ครูผู้ช่วย, คศ.1, คศ.2 (ชำนาญการ), คศ.3 (ชำนาญการพิเศษ), คศ.4 (เชี่ยวชาญ), คศ.5 (เชี่ยวชาญพิเศษ)**
   - สลับฐานคำนวณอัตโนมัติ (**ฐานล่าง** vs **ฐานบน**) ตามระดับเงินเดือนปัจจุบัน
   - ปัดเศษขึ้นเป็นจำนวนเต็ม **10 บาท** ทุกกรณีตามระเบียบ ก.ค.ศ.
   - รองรับการอาศัยเบิกข้ามขั้น (Overflow Ceiling) และการคำนวณเงินค่าตอบแทนพิเศษกรณีเงินเดือนชนเพดาน
   - ตารางเปรียบเทียบการได้รับร้อยละต่างๆ (2.0% - 4.0%) ในรอบนั้นๆ
   - ปุ่ม **"คัดลอกส่ง LINE"** ช่วยสรุปผลเป็นข้อความพร้อมส่งต่อในกลุ่มไลน์ได้ทันที

2. **ระบบจำลองอนาคต & วางแผนเกษียณถึงอายุ 60 ปี และเงินก้อน กบข.:**
   - คำนวณการเลื่อนเงินเดือน 2 รอบ/ปี ต่อเนื่องจนถึงวันเกษียณอายุราชการ
   - กำหนดแผนเลื่อนวิทยฐานะตามช่วงอายุที่ต้องการ (เช่น เลื่อน คศ.2 ตอนอายุ 32, เลื่อน คศ.3 ตอนอายุ 37)
   - กราฟแสดงการเติบโตของเงินเดือนและรายรับรวม (Interactive Chart.js)
   - ค้นหาเงินเดือนเป้าหมายตามอายุที่ระบุ (Target Age Lookup)
   - ประมาณการเงินบำนาญรายเดือนตามสูตร กบข. (เงินเดือนเฉลี่ย 60 เดือนสุดท้าย × เวลาราชการ / 50 เพดานไม่เกิน 70%)
   - **จำลองเงินก้อน กบข. ณ วันเกษียณ (GPF Wealth Lump Sum):** คำนวณเงินสะสมของสมาชิก (3-20%), เงินสมทบจากรัฐ 3%, เงินชดเชยจากรัฐ 2% พร้อมดอกเบี้ยทบต้น (Compound Interest) ปรับอัตราผลตอบแทนคาดหวังได้ 2.5% - 5.5% ต่อปี
   - ส่งออกข้อมูลเป็นไฟล์ Excel/CSV หรือสั่งพิมพ์รายงาน (Print / Save PDF)

3. **เครื่องมือนับเวลาทำวิทยฐานะ วPA (PA Countdown & Qualification):**
   - คำนวณเวลาราชการและระยะเวลาครองวิทยฐานะปัจจุบันแบบเรียลไทม์ (ปี เดือน วัน)
   - ตรวจสอบคุณสมบัติการขอรับการประเมินเลื่อนสู่วิทยฐานะถัดไป (คศ.2, คศ.3, คศ.4, คศ.5)
   - รองรับ **เกณฑ์ลดระยะเวลาตาม ว16/2564** จาก 4 ปี เหลือ 3 ปี (วุฒิ ป.โท / ป.เอก, ภาษาอังกฤษ CEFR B2 ขึ้นไป, โรงเรียนพื้นที่พิเศษ)
   - ตรวจสอบความสมบูรณ์ของรอบการประเมิน PA ครบ 3 รอบปีงบประมาณ
   - แถบ Progress Bar แสดงความก้าวหน้าสู่เป้าหมาย พร้อมปุ่มสรุปส่ง LINE

4. **ระบบคำนวณและวางแผนภาษีข้าราชการครู (ภ.ง.ด.91 - Teacher Tax Planning):**
   - คำนวณเงินได้พึงประเมินประจำปี (เงินเดือนรวมทั้งปี + เงินวิทยฐานะ + ค่าตอบแทนพิเศษ)
   - หักค่าใช้จ่ายตามกฎหมาย 50% สูงสุด 100,000 บาท
   - หักค่าลดหย่อนส่วนบุคคลและครอบครัว (ผู้มีเงินได้ 60,000 บ., คู่สมรส, บุตร, บิดามารดา)
   - หักเงินสะสม กบข. ตามจ่ายจริง (สูงสุด 500,000 บาท)
   - หักค่าลดหย่อนดอกเบี้ยบ้าน ประกันชีวิต ประกันสุขภาพ กองทุน SSF/RMF/Thai ESG และเงินบริจาค e-Donation (หักได้ 2 เท่า)
   - แสดงตารางจำแนกขั้นภาษีอัตราก้าวหน้า (0% - 35%) อย่างโปร่งใสชัดเจน
   - คำแนะนำเทคนิคการประหยัดภาษีเฉพาะสำหรับข้าราชการครู พร้อมปุ่มคัดลอกสรุปภาษีส่ง LINE

5. **ตารางฐานในการคำนวณ & ความรู้เกณฑ์ ก.ค.ศ. (ว20):**
   - ตารางอ้างอิงช่วงเงินเดือน ฐานล่าง ฐานบน และเงินวิทยฐานะครบทุกอันดับ
   - คำอธิบายหลักเกณฑ์สำคัญที่ครูควรรู้

6. **ระบบจำค่าอัตโนมัติ (LocalStorage Autosave) & Progressive Web App (PWA):**
   - บันทึกค่าที่กรอกไว้ในเครื่องอัตโนมัติ เมื่อเปิดเข้ามาใหม่ไม่ต้องกรอกข้อมูลเดิมซ้ำ
   - รองรับการติดตั้ง "เพิ่มลงในหน้าจอหลัก" (Add to Home Screen) บนโทรศัพท์มือถือ iOS และ Android ใช้งานเสมือนแอปพลิเคชันได้ทันที

## 🚀 การติดตั้งและเปิดทดสอบในเครื่อง (Local Development)

ระบบนี้พัฒนาด้วย HTML5, Tailwind CSS, และ JavaScript แบบ Pure Static Client-Side จึงสามารถรันได้ทันทีโดยไม่ต้องติดตั้ง Backend หรือ Database:

```bash
# วิธีที่ 1: รันด้วย npx serve
npm run dev
# หรือ
npx serve . -l 3000

# วิธีที่ 2: รันด้วย Python (ถ้ามีติดตั้งในเครื่อง)
python -m http.server 3000
```
เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

## 🌐 ขั้นตอนการเชื่อมต่อ GitHub และ Deploy ขึ้น Vercel

### ขั้นตอนที่ 1: สร้าง Repository บน GitHub
1. ล็อกอินเข้า [GitHub](https://github.com)
2. คลิกปุ่ม **New Repository** (หรือเครื่องหมาย `+` มุมขวาบน)
3. ตั้งชื่อ Repository เช่น: `kru-salary-calculator` หรือ `teacher-salary-calculator`
4. เลือกระดับเป็น **Public** หรือ **Private** ตามต้องการ
5. **ไม่ต้อง** ติ๊กถูกที่ "Add a README file" (เนื่องจากเรามีไฟล์พร้อมแล้ว)
6. คลิก **Create repository**

### ขั้นตอนที่ 2: Push โค้ดจากเครื่องขึ้น GitHub
เปิด Terminal ในโฟลเดอร์นี้ แล้วรันคำสั่ง:

```bash
# 1. เริ่มต้น Git (ถ้ายังไม่ได้ทำ)
git init

# 2. เพิ่มไฟล์ทั้งหมดเข้า Staging
git add .

# 3. บันทึก Commit
git commit -m "feat: initial commit - thai teacher salary calculator & pension simulator"

# 4. ตั้งชื่อ Branch หลักเป็น main
git branch -M main

# 5. เชื่อมต่อ Remote Repository ไปยัง GitHub ของคุณ (แทนที่ username ด้วยของคุณ)
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/kru-salary-calculator.git

# 6. Push ข้อมูลขึ้น GitHub
git push -u origin main
```

### ขั้นตอนที่ 3: เชื่อมต่อ Vercel เพื่อ Deploy อัตโนมัติ (CI/CD)
1. ไปที่ [Vercel](https://vercel.com) และล็อกอินด้วยบัญชี **GitHub**
2. คลิกปุ่ม **"Add New..."** -> เลือก **"Project"**
3. ที่หัวข้อ **Import Git Repository** ให้เลือก repository `kru-salary-calculator` ที่เพิ่งสร้างขึ้น
4. ตั้งค่าโปรเจกต์:
   - **Framework Preset:** เลือก `Other`
   - **Root Directory:** `./` (ปล่อยว่างไว้ตามค่าเริ่มต้น)
   - **Build and Output Settings:** ไม่ต้องแก้ไขใดๆ (Static Site Deploy ได้ทันที)
5. คลิกปุ่ม **"Deploy"**
6. ภายใน 10-20 วินาที ระบบจะประมวลผลเสร็จสิ้นและให้ URL ประจำโปรเจกต์ เช่น:
   ```text
   https://kru-salary-calculator.vercel.app
   ```

### 🔄 ระบบ Continuous Deployment (อัตโนมัติ)
เมื่อเชื่อมต่อแล้ว ทุกครั้งที่คุณแก้ไขโค้ดในเครื่องแล้วรัน:
```bash
git add .
git commit -m "update: ปรับปรุงสูตรหรือหน้าเว็บ"
git push
```
Vercel จะตรวจจับและทำการ Deploy เวอร์ชันใหม่ให้อัตโนมัติทันทีภายในไม่กี่วินาที โดยไม่ต้องกด Deploy ด้วยตัวเอง

```text

```
